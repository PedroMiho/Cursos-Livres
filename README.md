# Cursos Livres — Estudos, Exercícios e Projetos

Este repositório reúne exercícios, anotações, desafios e projetos desenvolvidos durante cursos livres, bootcamps e trilhas de aprendizagem na área de Tecnologia da Informação.

O conteúdo registra minha evolução profissional e prática em programação, desenvolvimento web, Java, JavaScript, TypeScript, React e estruturas de dados.

## Objetivo

Organizar os materiais produzidos durante cursos complementares e manter um histórico prático dos conhecimentos adquiridos em diferentes plataformas de ensino.

Os códigos armazenados neste repositório possuem finalidade educacional e podem representar diferentes etapas do processo de aprendizagem.

## Como utilizar os materiais

1. Escolha a plataforma ou formação desejada.
2. Acesse a pasta correspondente.
3. Localize o módulo, exercício ou projeto.
4. Consulte o código desenvolvido.
5. Verifique os requisitos específicos antes da execução.

Para baixar o repositório:

```bash
git clone https://github.com/PedroMiho/Cursos-Livres.git
```

Depois, acesse a pasta:

```bash
cd Cursos-Livres
```

## Execução dos projetos

### HTML, CSS e JavaScript

Projetos estáticos podem ser abertos diretamente no navegador ou executados com uma extensão como o Live Server.

### Node.js, TypeScript e React

Verifique se o Node.js e o npm estão instalados:

```bash
node --version
npm --version
```

Na pasta que contém o arquivo `package.json`, instale as dependências:

```bash
npm install
```

Depois, consulte os scripts disponíveis:

```bash
npm run
```

### Java

Verifique se o Java está instalado:

```bash
java --version
```

Quando o projeto utilizar Maven:

```bash
mvn --version
mvn spring-boot:run
```

## Aviso sobre dependências

Pastas como `node_modules` não precisam ser baixadas ou adicionadas manualmente ao controle de versão.

As dependências dos projetos Node.js devem ser instaladas por meio do arquivo `package.json`:

```bash
npm install
```
